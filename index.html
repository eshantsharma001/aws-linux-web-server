Project 1 • Cloud Infrastructure Live on EC2

AWS Linux Web Server

A hands-on cloud administration project showing how a virtual Linux server inside a VPC serves a live site through Nginx over Port 80, paired with dedicated EBS storage, S3 backups, IAM roles, and CloudWatch monitoring.

How Traffic & Deployment Flow

Code / Site Files → Ubuntu EC2 (/var/www/html) → Nginx (Port 80) → Browser via Public IP

What This Project Covers

01

EC2 + Ubuntu Linux + VPC

Runs an Ubuntu virtual server inside a private AWS Virtual Private Cloud with controlled network access and a public IP for reachability.

02

Nginx Web Server

Listens on Port 80 and serves files directly from /var/www/html to visitors opening the server address in a browser.

03

EBS Volume + S3 Backups

Attaches, formats, and mounts a persistent EBS volume for extra disk space while syncing backups safely into an Amazon S3 bucket.

04

IAM Roles + CloudWatch

Grants the EC2 instance an IAM role for S3 access without storing static keys, and tracks health metrics like CPU utilization in CloudWatch.
